## TE_TUBE USER GUIDE

Welcome to Te_Tube! This guide will help you navigate and use the software effectively.

## MAIN INTERFACE

The application is organized into four main tabs:
1. Search: Find videos by entering keywords or using voice search.
2. Favorite Videos: Quick access to your saved content.
3. Watch History: Review videos you've previously watched.
4. Process via link: Directly play or download a video using its URL.

You can also access two important dialogs at any time:

- Settings (F4): Configure download folder and voice language.
- Help (F1): Access this documentation.

## HOW TO SEARCH AND PLAY
1. Navigate to the Search tab.
2. Type your keywords into the "Search Query" box and press Enter, OR select the "Voice Search" button.
3. For Voice Search: The software will say "Listening...", speak your query into the microphone. It will automatically search when you finish.
4. Use the Arrow keys to browse the results list.
5. Press Enter on a selected item to start playing the video. A "Playing" dialog will appear while the stream is loading.
6. Alternatively, open the context menu (Application key or Shift+F10) for more options like "Play as Audio".

## DOWNLOADING CONTENT (WITH TIME RANGE)

You can download any video from the Search, Favorites, or History lists:
1. Open the context menu on the desired item and select "Download".
2. A Download Options dialog will appear.
3. Select your preferred format (MP4 Video, M4A Audio, MP3 Audio, WAV Audio).
4. (Optional) Check "Download specific time range" if you only want a portion of the video.
    - Enter the Start and End times in HH:MM:SS format (e.g., 00:01:00 to 00:02:30).
    - If checked, the software will automatically cut the video/audio directly during download, saving time and bandwidth.
5. Press Enter or click Download. Files are saved to your configured download folder.

## HANDLING LINKS FROM CLIPBOARD

Te_Tube monitors your clipboard in the background. If you copy a YouTube link:
1. Te_Tube will pop up a dialog.
2. You can choose to Play, Download, or Cancel.

## MANAGING SETTINGS

Press F4 or go to Main -> Settings to configure:

- General: Change the folder where downloaded files are saved.
- Voice Search: Select your preferred language for voice recognition (e.g., Vietnamese, English).

## SOFTWARE UPDATES

The app checks for updates on startup. If a new version is available, you will be prompted to update. You can also manually check for updates via the Main menu.
