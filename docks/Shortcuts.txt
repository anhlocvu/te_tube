TE_TUBE KEYBOARD SHORTCUTS

Te_Tube is designed to be fully operable via keyboard, which is essential for users of screen readers like NVDA.

GLOBAL SHORTCUTS
- F1: Open the Help tab and Documentation.
- Ctrl + D: Open the downloads folder in File Explorer.
- Alt + F4: Exit the application.
- Tab or Shift + Tab: Move focus between different controls (input boxes, lists, buttons).
- Ctrl + Tab: Switch between tabs (Search, Favorites, History, etc.).

LIST NAVIGATION (Search Results, Favorites, History)
- Up and Down Arrows: Move through the list of videos.
- Enter or Numpad Enter: Play the selected video.
- Shift + F10 or Menu Key: Open the context menu for the selected item.

MPV PLAYER CONTROLS (During Playback)
When the player window is active, use these standard MPV shortcuts:
- Space: Toggle Pause and Play.
- Left and Right Arrows: Seek backward or forward 5 seconds.
- Up and Down Arrows: Seek backward or forward 1 minute.
- 9 and 0: Decrease or Increase volume.
- m: Mute or Unmute audio.
- f: Toggle Fullscreen mode.
- q: Stop playback and close the player window.
- [ and ]: Decrease or Increase playback speed.

HELP TAB SHORTCUTS
- Up and Down Arrows: Navigate the list of documentation files.
- Tab: Move focus to the text viewer to read the content.
- Alt + R: Return to the Search tab.
- Alt + C: Clear the text viewer and return focus to the file list.
